HOW IT WORKS

Three reads, one number.

No black box — each step pulls a specific, checkable fact from the chain itself.

1

Paste an address

Any contract deployed on Robinhood Chain, Base, Arbitrum, Arc or Ethereum. No wallet connection, no account needed.

2

NettoLens reads the chain

Verification status via Blockscout, ownership and admin roles via on-chain calls and events, holder spread from live token data, liquidity from DEXScreener.

3

Get a score you can act on

Each check is shown individually, plus one combined number — so you can see exactly why.

WHAT IT CHECKS

Three layers, one score.

Each scan combines on-chain contract data, ownership status, and wallet relationships into a single number you can act on in seconds.

Contract & ownership checks

Verification status, whether the owner key has been renounced, and who still holds admin, mint, pause or seize roles — including Base's native B20 tokens.

Live

Holder concentration

What share of supply sits in the top 10 wallets — the clearest early signal of a coordinated dump.

Live

Wallet network map

Checks whether top holders were funded directly by the deployer — a common sign of wash-traded, sybil holders. Sync-trading detection is still planned.

THE NETWORK MAP

A picture is worth a thousand transactions.

  • Funding trails · live
    Checks whether each top holder was funded directly by the deployer wallet — a classic sign of sybil holders padding the count.
  • Repeat offenders · live
    Counts how many other contracts the deployer has recently created.
  • Sync detection · planned
    Flag wallets that buy or sell within seconds of each other — a sign of a single actor behind many addresses.
